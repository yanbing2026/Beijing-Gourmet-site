# Beijing Gourmet

A restaurant website for **Beijing Gourmet** — authentic Beijing cuisine served with tradition and warmth.

## Site Structure

```
├── index.html      # Main page (hero, about, specialties, menu, gallery, contact)
├── style.css       # Full stylesheet (dark theme, responsive)
├── script.js       # Interactivity (nav toggle, menu tabs, scroll effects, forms)
└── README.md       # This file
```

## Features

- **Hero section** with parallax-like background and animated entrance
- **About section** with story and signature dish highlight
- **Specialties grid** — Peking Duck, Xiao Long Bao, Dim Sum, Noodles & Rice
- **Interactive menu** with category tabs (Starters, Noodles & Rice, Main Courses, Dim Sum, Desserts)
- **Photo gallery** section with dish and venue placeholders
- **Contact & reservation form** with date/time/guests selection
- **Footer** with quick links, services, and newsletter signup
- **Fully responsive** — mobile hamburger nav, collapsible grids, touch-friendly

## Design

- Dark, elegant theme with warm gold accents
- Serif (Playfair Display) for headings, sans-serif (Inter) for body
- Smooth scroll, staggered entrance animations, and scroll-based navbar styling

## Local Development

Open `index.html` directly in a browser, or serve with any static server:

```bash
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## Deployment

This repository is configured for GitHub Pages. After pushing to `main`, the site builds automatically at the URL above.
